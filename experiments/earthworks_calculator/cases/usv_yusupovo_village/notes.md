## Важное допущение по ручной разработке

Расчётный объём ручной разработки по формулам равен `44.69 м3`.

В серой зоне сметы Елены строка "Разработка грунта вручную" должна дать `62573 руб.` при внутренней ставке `1400 руб./м3`. Если умножить строго `44.69 * 1400`, получится `62566 руб.`

Чтобы повторить эталонную смету без скрытой магии в коде, в `input.json` явно добавлено отдельное поле:

```json
"manual_excavation_quantity_for_estimate_m3": 44.695
```

Именно это количество используется только для строки внутренней сметы. Объёмный расчёт при этом остаётся `manual_excavation_total_m3 = 44.69`.

## Правило для следующих кейсов

Каждый новый проект добавлять отдельной папкой в `cases/`:

```text
cases/<case_name>/
├── input.json
├── expected.json
└── notes.md
```

Результаты запуска сохраняются в `output/<case_name>/`.
