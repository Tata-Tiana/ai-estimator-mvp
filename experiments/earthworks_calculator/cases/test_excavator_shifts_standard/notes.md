# Test excavator shifts standard

Тестовый кейс для production-стандарта расчёта смен экскаватора от объёма механизированной выемки.

## Проверочный расчёт

- Площадь котлована: `330 м2`.
- Глубина механизированной выемки: `0.6 м`.
- Объём механизированной выемки: `330 * 0.6 = 198 м3`.
- Производительность экскаватора: `80 м3/смена`.
- Смены экскаватора: `ceil(198 / 80) = 3`.

## Важно

- `pit_excavation_depth_m` не равен `manual_refinement_depth_m`.
- `manual_refinement_depth_m = 0.08` относится к ручной доработке дна котлована.
- `excavator_shifts` не задаётся вручную в production-режиме.
