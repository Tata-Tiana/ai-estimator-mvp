# Хорошевка 14

Второй эталонный кейс расчёта раздела "Земляные работы".

## Источники

- PDF-проект Хорошевка 14: `experiments/pdf_tests/projects/horoshevka_14/`
- AI-карточка проекта: `experiments/ai_tests/projects/horoshevka_14/output/project_card_full.md`
- Часть недостающих чисел взята вручную из сметы.

Эта смета не разбиралась дословно с Еленой, поэтому кейс фиксирует повторение имеющейся сметы, а не новое правило от инженера.

## Что дала карточка проекта

Карточка проекта нашла общие данные, песчаное основание `300 мм` и геотекстиль, но не дала готовую структуру `earthworks_inputs` для калькулятора.

Для повторения серой внутренней части сметы вручную заданы:

- `manual_excavation_quantity_for_estimate_m3 = 32.393`
- `sand_order_volume_m3 = 190` через `quantity_overrides`
- `geotextile_material_quantity_m2 = 300` через `quantity_overrides`

## Важное допущение по ручной разработке

Расчётный объём по формулам:

```text
manual_pit_volume_m3 = 262 * 0.08 = 20.96
manual_excavation_total_m3 = 20.96 + 11.43 = 32.39
```

В смете видимое количество ручной доработки `32.4 м3`, но для точного попадания в `38872 руб.` при ставке `1200 руб./м3` используется явное поле:

```json
"manual_excavation_quantity_for_estimate_m3": 32.393
```

Эта подстройка не спрятана в коде и применяется только к строке серой внутренней сметы.

## Важное допущение по песку и геотекстилю

По формулам калькулятор получает:

- `sand_order_volume_m3 = 240`
- `geotextile_rolls = 3`

Но для повторения эталонной сметы Хорошевки используются явные количества из сметы:

```json
"quantity_overrides": {
  "sand_order_volume_m3": 190,
  "geotextile_material_quantity_m2": 300
}
```

То есть объёмный расчёт сохраняется в `volume_result`, а строки серой сметы повторяют сметные количества.

## Особенности строк сметы

- В этом кейсе нет отдельных строк `communications_work` и `communications_material`.
- Коммуникации в смете указаны справочно как `50 м/п`, но в серую итоговую часть отдельными строками не включены.
- Нет отдельной строки `geotextile_laying`: работа по укладке сидит в строке материала геотекстиля.
- Для этого используется цена `geotextile_material_work_unit_price = 35`.
- Названия строк `manual_excavation` и `sand_filling` отличаются от кейса ЮСВ, поэтому они явно заданы через `line_name_overrides`.
