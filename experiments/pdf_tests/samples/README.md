Новый рекомендуемый порядок:

1. Создать папку проекта в `experiments/pdf_tests/projects/<project_name>/`.
2. Положить PDF в `experiments/pdf_tests/projects/<project_name>/input/`.
3. Запустить:
   `../.venv/bin/python3 experiments/pdf_tests/run_pdf_parser.py`
4. Указать имя проекта, например `horoshevka_14`.
5. Указать имя части PDF, например `kr1_below_floor` или `kr2_above_floor`.
6. Смотреть результаты в `experiments/pdf_tests/projects/<project_name>/output/`.
