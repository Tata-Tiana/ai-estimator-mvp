# PDF Projects

Здесь лежат PDF-эксперименты, сгруппированные по домам.

Формат:

```text
projects/<project_name>/
├── input/
│   ├── kr1_below_floor.pdf
│   └── kr2_above_floor.pdf
├── output/
│   ├── kr1_below_floor/
│   └── kr2_above_floor/
└── notes.md
```

Для проектов, где документация разбита иначе, имена частей можно менять, но смысл должен быть понятным человеку.
