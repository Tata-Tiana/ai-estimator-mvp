Эта папка оставлена для локальных заметок по старому формату эксперимента.

Новый формат для серии домов:

```text
experiments/ai_tests/projects/<project_name>/
├── input/
│   └── sources.json
├── output/
└── notes.md
```

Внутри создаются:
- `project_card_full.json`
- `project_card_full.md`
- `materials_extracted.xlsx`
- `estimate_scope_mapping.xlsx`
- `missing_data.txt`
- `warnings.txt`
- `sources.json`
