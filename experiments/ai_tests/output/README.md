Эта папка служит для локальных заметок и промежуточных артефактов эксперимента.

Основной результат анализа сохраняется в:
`data/output/ai_project_cards/{datetime}/`

Внутри создаются:
- `project_card_full.json`
- `project_card_full.md`
- `materials_extracted.xlsx`
- `estimate_scope_mapping.xlsx`
- `missing_data.txt`
- `warnings.txt`
- `sources.json`
