# test_floor_slab_1_no_beams

Проверяет, что при полном отсутствии балок (`beams.items: []`, никаких override-скаляров) все
связанные с балками величины (объём бетона балок, площадь опалубки балок, длина/площадь балок для
утепления) корректно становятся 0 и ничего не падает — ни в производственном режиме утепления
(`spec_work_quantities`), ни в производственном режиме арматуры (`spec_length_items`).

До этого кейса ни один существующий тест `floor_slab_1` не проверял отсутствие балок вообще — все
7 кейсов имели непустой `beams.items`. У `floor_slab_2` этот путь уже был покрыт (5 из 6 кейсов без
балок), у `floor_slab_1` — не был. Добавлено 2026-07-12 при проверке поведения нового override
`beams_concrete_volume_m3`.

Собран из `test_floor_slab_1_insulation_spec_quantities` (тот же production-режим утепления и
арматуры), с обнулёнными балками.
