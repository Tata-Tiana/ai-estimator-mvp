# test_floor_slab_1_beams_concrete_volume_spec

Проверяет опциональный override `beams_concrete_volume_m3`: готовый итог объёма бетона балок из
спецификации ПДФ, вместо суммы по `beams.items[].concrete_volume_m3`.

Балки (Б-1 7×0.3×0.25, Б-2 7.2×0.3×0.68, Б-3 9×0.3×0.43) — те же, что в базовом кейсе.
`beams_concrete_volume_m3: 3.145` взят из реальной "Спецификации Ж/Б балок" проекта ЮСВ (КР2, лист 22,
готовая строка "Итого"). Расчёт по геометрии даёт 3,1548 м3 — мелкое расхождение округления в самой
спецификации, `concrete_volume_delta_m3` = -0.0098, меньше порога 0.01, предупреждение не срабатывает.

`beam_items` всё равно остаётся нужным полностью: он используется не только для объёма бетона, но и
для площади опалубки (свой отдельный override уже был) и длины/площади утепления балок, для которых
override не добавлялся.
