# Test waterproofing spec area

Тестовый кейс для production-стандарта площади гидроизоляции.

## Проверяемое правило

Площадь гидроизоляции берётся готовым значением из спецификации проекта:

```text
waterproofing_area_m2 = 24.3
```

По методике Елены эта площадь равна площади опалубки фундаментной плиты.

## Что не используется

В этом кейсе не нужны:

- `slab_formwork_perimeter_m`;
- `slab_edge_height_m`.
- `non_insulated_edge_lengths_m`.

Старая формула `perimeter * height` оставлена только для legacy-кейса.

## Проверочный расчёт

- Работа по гидроизоляции: `24.3 * 350 = 8505`.
- Праймер: `24.3 * 0.3 / 18 = 0.405 -> 1 канистра`.
- Мастика: `24.3 * 1 * 2 / 18 = 2.7 -> 3 ведра`.
- Площадь работ по ЭППС 100 мм торец: `1.75 / 0.1 = 17.5 м2`.
- Геометрическая проверка по участкам без утепления выключена.
