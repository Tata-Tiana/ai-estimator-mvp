# Гидроизоляция фундаментной плиты

Считается только серая внутренняя себестоимость. Клиентская часть не считается.

## Подтверждённая логика

1. Площадь гидроизоляции считается как:
   борта / внешний периметр плиты × высота плиты.
   В кейсе:
   `81 × 0.3 = 24.3 м2`.

## Legacy по площади гидроизоляции

Этот кейс использует старую формулу:

```text
waterproofing_area_m2 = slab_formwork_perimeter_m * slab_edge_height_m
```

В новом production-стандарте площадь гидроизоляции берётся готовым значением из спецификации проекта:

```text
waterproofing_area_m2
```

По методике Елены эта площадь равна площади опалубки фундаментной плиты.

Старый `expected.json` не менять.

2. Гидроизоляция битумной мастикой в 2 слоя - это работа:
   `24.3 × 350 = 8505`.

3. Праймер:
   площадь × `0.3 л/м2` / `18 л`,
   округление вверх до целой канистры.

4. Мастика:
   площадь × `1 кг/м2` × `2 слоя` / `18 кг`,
   округление вверх до целой банки.

5. Утепление стен плиты ЭППС 100 мм:
   площадь берётся из спецификации:
   `1.75 м3 / 0.1 = 17.5 м2`.

6. Геометрическая проверка площади утепления:
   `(81 - 8.2 - 2 - 5.3) × 0.3 = 19.65 м2`.
   Но в строку сметы берётся `17.5 м2` из спецификации.

## Legacy по участкам без утепления

Этот кейс использует `non_insulated_edge_lengths_m` только для геометрической проверки площади утепления:

```text
(slab_formwork_perimeter_m - sum(non_insulated_edge_lengths_m)) * slab_edge_height_m
```

В новом production-стандарте эти участки не требуются.

Площадь работ по ЭППС 100 мм торец считается от объёма ЭППС из спецификации:

```text
eps100_wall_insulation_area_m2 = eps100_wall_volume_m3 / 0.1
```

7. Пеноплэкс ГЕО 100 мм:
   `17.5 × 0.1 × 1.05 = 1.8375 м3`.
   Потом округление до пачек:
   `1.8375 / 0.2776 = 6.6192 -> 7 пачек`.
   `7 × 0.2776 = 1.9432 м3`.

8. Клей-пена:
   подтверждённое правило Елены:
   1 баллон на 10 м2,
   всегда округлять вверх,
   минимум 1 баллон.

9. Логистика:
   2% от суммы основных строк блока до логистики и расходников.

10. Расходные материалы:
   3% от суммы основных строк блока до логистики и расходников.

## Вопросы / открытые места

1. Коэффициенты 2% логистики и 3% расходников подтвердить для других разделов отдельно.
2. Если нет спецификации по ЭППС 100 мм торец, можно ли брать геометрический расчёт как fallback.
3. Цены материалов должны потом уйти в price_profile.

## Режим цен

Эталонный кейс работает в режиме `locked_case_prices`: цены берутся из `input.json`.

Отдельный live-кейс с `price_registry_with_fallback` лежит в:

```text
experiments/waterproofing_calculator/cases/test_waterproofing_foundation_slab_live_prices/
```

Live-суммы могут отличаться от этого expected, потому что часть цен берётся из `price_registry`.
