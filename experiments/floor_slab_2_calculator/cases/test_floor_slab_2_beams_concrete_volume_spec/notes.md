# test_floor_slab_2_beams_concrete_volume_spec

Проверяет опциональный override `beams_concrete_volume_m3`: готовый итог объёма бетона балок из
спецификации ПДФ, вместо суммы по `beams.items[].concrete_volume_m3`.

Значения балок (Б-1 7×0.3×0.25, Б-2 7.2×0.3×0.68, Б-3 9×0.3×0.43) и `beams_concrete_volume_m3: 3.145`
взяты из реальной "Спецификации Ж/Б балок" проекта ЮСВ (КР2, лист 22) — там же готовая строка
"Итого" даёт 3,145 м3, а расчёт по геометрии даёт 3,1548 м3 (мелкое расхождение округления в самой
спецификации). `concrete_volume_delta_m3` = -0.0098, меньше порога 0.01, поэтому предупреждение не
срабатывает — это ожидаемое поведение.

`beam_items` в этом кейсе всё равно нужен полностью: он используется не только для объёма бетона,
но и для площади опалубки балок и длины/площади утепления, для которых override не добавлялся.
