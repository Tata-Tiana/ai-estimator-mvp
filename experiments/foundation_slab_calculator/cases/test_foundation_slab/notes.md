# Test Foundation Slab Notes

## Что считается

1. Считается только серая внутренняя себестоимость.
2. Клиентская часть не считается.
3. Строка "Монтаж мембраны" - работа по м2.
4. Строка "Planter Standard" - материал, считается через рулоны.
5. Строка "PLANTERBAND" зависит от количества рулонов мембраны: `rolls * 4`.
6. Пиломатериал считается как `площадь опалубки * 0.05`, без коэффициента `1.5`.
7. `0.05` - это толщина 50 мм.
8. Для фанеры используется рабочая площадь листа `2.25 м2`.
9. Термовкладыш по работе считается по длине `21.5 м.п.`, но для материала считаются штуки через `длина / 0.6`.
10. В расчёте термовкладыша есть разные размеры:
    - control volume использует `0.3`;
    - EPS material использует `0.25`.
    Это требует подтверждения Елены.
11. Арматура считается универсальной функцией по весу, кг/м, запасу 5%, длине прутка и округлению.
12. Для Ø6 длина прутка `6 м`, не `11.7 м`.
13. Доставка арматуры - manual/fixed line, потому что она зависит от общего металла по листу "Коробка", а не только от фундаментной плиты.
14. Бетонирование - работа по проектному объёму `81 м3`.
15. Бетон - материал по объёму `81 * 1.05` с округлением вверх до `0.5 м3`.
16. Доставка бетона считается от объёма бетона к заказу / `9 м3`, округление вверх.
17. Логистика, расходники и технадзор пока manual/fixed lines.

## Статус кейса

Кейс нужен для повторения серой внутренней части раздела "Устройство фундаментной плиты дома, террасы, крыльца (250мм,300мм)".

Если итог по Excel отличается от текущих `internal_totals`, код не подгоняется молча. Нужно добавить отсутствующие строки или явно зафиксировать отличие в `expected.json` и notes.

## Комментарии Елены / подтверждённые правила

### Мембрана PLANTER

1. Площадь для монтажа мембраны берётся из спецификации мембраны.
2. Если точной спецификации нет, как грубый предварительный вариант можно брать площадь котлована.
3. Строка "Монтаж мембраны PLANTER стандарт" остаётся работой по м2.
4. Строка "Planter Standard Технониколь" остаётся материалом, считается через рулоны, нахлёст и округление.
5. PLANTERBAND считается всегда по правилу: `количество PLANTERBAND = количество рулонов мембраны * 4`. То есть 4 шт на 1 рулон мембраны - подтверждённое постоянное правило.

### Опалубка / борта

1. "Борта" = внешний периметр фундаментной плиты.
2. Если есть плиты разной толщины, Елена подтвердила, что можно брать максимальную толщину. Комментарий: связано с досками/отбортовкой, "три по 100 мм".
3. Формула остаётся: `formwork_area_m2 = slab_formwork_perimeter_m * slab_edge_height_m`.
4. `slab_edge_height_m` для типового расчёта можно брать как максимальную толщину плиты.

### Фанера

1. Сейчас текущий кейс считает фанеру через рабочую площадь листа `2.25 м2`, и это даёт совпадение с Excel.
2. Елена уточнила, что фактически расчёт зависит от раскроя листа.
3. Можно считать по фактическому размеру листа `1.52 * 1.52 м`.
4. В идеале нужно смотреть раскрой фанеры и добавлять 5%.
5. Количество листов всегда округляется вверх до целого.
6. ВАЖНО: текущий кейс не ломать. Новый метод расчёта фанеры добавлен опционально через `plywood_calc_method`, а текущий кейс остаётся на `working_area`.

### Пиломатериал

1. `0.05` - это толщина пиломатериала 50 мм.
2. Пиломатериал всегда считают как: `timber_volume_m3 = formwork_area_m2 * 0.05`.
3. Дополнительного запаса на пиломатериал в этой формуле нет.
4. Можно считать точно, то есть деньги считать от точного значения `1.215`, даже если в смете отображается `1.2`.

### ЭППС / Пеноплэкс

1. Пеноплэкс = ЭППС.
2. Площадь укладки ЭППС 50 мм считается из объёма по спецификации: `area_m2 = volume_m3 / thickness_m`.
3. В спецификации могут быть "торец" и "низ".
4. Объём `13.5 м3` относится к площади всей плиты / ЭППС под плитой.
5. ЭППС 50 мм и ЭППС 100 мм вместе дают термовкладыш 150 мм, потому что материала 150 мм как отдельной позиции нет.
6. Термовкладыш 150 мм собирается из двух слоёв:
   - Пеноплэкс 50 мм
   - Пеноплэкс 100 мм
7. Если нет террасы/крыльца/холодной плиты - термовставок не будет. При этом крыльцо обычно есть всегда, но не всегда требует термовставки.
8. По размеру `0.25 / 0.3`: Елена уточнила, что должно быть `0.3`, если высота плиты 300 мм. Иногда бывает `0.25`, но не принципиально, потому что потом идёт округление до пачек.
9. Объём одной пачки Пеноплэкс ГЕО 50 мм - `0.2776 м3`.
10. Запас 5% на Пеноплэкс 100 мм для термовкладыша не применять.
11. Запас 5% применяется к ЭППС под плитой, но не к ЭППС 100 мм для термовкладыша.

### Арматура / доставка металла

1. Доставка арматуры считается по общему весу металла листа "Коробка".
2. В одну доставку идёт не более 10 тонн металла.
3. Нужно стараться максимально загружать манипулятор.
4. Общее правило: `suggested_delivery_trucks = ceil(total_box_metal_weight_kg / 10000)`.
5. При этом доставка может распределяться по разделам: одна доставка на фундамент, потом доставки в других разделах.
6. Для текущего `foundation_slab_calculator` доставка пока не переносится на уровень `box_calculator`, но добавлен контрольный расчёт `suggested_trucks`.
7. Текущая строка доставки арматуры остаётся manual/fixed line, если в input явно задано `rebar_metal_delivery_trucks`.
