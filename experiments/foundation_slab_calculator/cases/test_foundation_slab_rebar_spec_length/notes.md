# Test case: rebar spec length standard

Этот кейс проверяет новый стандарт Елены по арматуре фундаментной плиты.

## Что проверяется

- Арматура приходит из спецификации в м.п., а не в кг.
- `weight_parts_kg` не требуется.
- `source_length_m` умножается на `rebar_waste_coeff`.
- Закупочная длина округляется до целых хлыстов через `rod_length_m`.
- Стоимость считается от закупочной длины в м.п.
- Вес по спецификации считается как `source_length_m * kg_per_meter`.
- Вес для доставки считается как `order_length_m * kg_per_meter`.
- Контрольная плотность армирования считается от проектного и закупочного веса.

## Важно

`kg_per_meter`, `rod_length_m` и `unit_price_per_m` пока находятся в `input.json` тестового кейса.
В production они должны приходить из `price_registry` / каталога арматуры.

Строка доставки металла в этом разделе остаётся manual/fixed. Финальная доставка металла должна считаться на уровне `box_calculator`, где суммируется металл по всем разделам коробки.

No Excel cell references.
