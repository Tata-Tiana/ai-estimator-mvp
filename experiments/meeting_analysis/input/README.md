# Meeting Analysis Input

Сюда кладутся папки с транскриптами созвонов.

Пример:

```text
experiments/meeting_analysis/input/2026-04-30_earthworks/
├── 01_intro.txt
├── 02_logic.txt
└── examples/
    ├── estimate_earthworks.png
    └── pit_plan.pdf
```

Правила:

- транскрипты должны быть `.txt`;
- файлы читаются и объединяются по имени файла;
- для правильного порядка удобно использовать префиксы `01_`, `02_`, `03_`;
- подпапка `examples/` необязательна;
- в `examples/` кладутся только точечные образцы: один раздел сметы, нужные листы PDF, небольшие текстовые пояснения.

Поддерживаемые примеры:

- `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`;
- `.pdf`;
- `.txt`, `.md`, `.csv`.

Не нужно класть сюда весь PDF проекта, всю смету или лишние скрины. Примеры нужны как подсказки для логики, а не как полный источник данных.
