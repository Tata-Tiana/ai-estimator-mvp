# Load Bearing Walls And Lintels Meeting Input

Сюда положить транскрибацию созвона с Еленой по разделу сметы:

```text
ВНЕШНИЕ И ВНУТРЕННИЕ НЕСУЩИЕ СТЕНЫ, ПЕРЕМЫЧКИ
```

Рекомендуемый формат:

```text
2026-05-15_load_bearing_walls_lintels/
├── 01_transcript.txt
├── 02_transcript.txt
└── examples/
    ├── estimate_walls_lintels.png
    └── project_walls_lintels.pdf
```

Правила:

- транскрипты должны быть `.txt`;
- если файлов несколько, пронумеровать их `01_`, `02_`, `03_`, чтобы они склеились в правильном порядке;
- в `examples/` положить только точечные материалы по этому разделу: скрин раздела сметы, нужные листы PDF, небольшие текстовые пояснения;
- не класть сюда весь проект или всю смету, если для анализа нужен только один раздел.
