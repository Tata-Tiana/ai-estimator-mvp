# Meeting Analysis Input: Устройство ростверкового фундамента

Папка для транскрибации и примеров по разделу:

```text
УСТРОЙСТВО РОСТВЕРКОВОГО ФУНДАМЕНТА
```

## Куда класть файлы

Транскрибацию созвона положить прямо в эту папку:

```text
experiments/meeting_analysis/input/2026-05-26_grillage_foundation/
```

Рекомендуемое имя:

```text
transcript.txt
```

Если есть скриншоты Excel, фрагменты сметы, схемы или заметки, положить их сюда:

```text
experiments/meeting_analysis/input/2026-05-26_grillage_foundation/examples/
```

## Важно

- Эта папка только для входных материалов анализа.
- Сами транскрибации и скриншоты обычно не коммитятся.
- После анализа расчётный калькулятор должен быть отдельным deterministic Python-калькулятором.
- AI может помогать разобрать транскрибацию, но не должен считать смету.
