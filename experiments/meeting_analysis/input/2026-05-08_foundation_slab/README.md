# Foundation Slab Meeting Input

Сюда положить транскрибацию созвона с Еленой по разделу фундаментной плиты.

Рекомендуемый формат:

```text
2026-05-08_foundation_slab/
├── 01_transcript.txt
├── 02_transcript.txt
└── examples/
    ├── estimate_foundation_slab.png
    └── project_foundation_slab.pdf
```

Правила:

- транскрипты должны быть `.txt`;
- если файлов несколько, пронумеровать их `01_`, `02_`, `03_`, чтобы они склеились в правильном порядке;
- в `examples/` положить только точечные материалы по фундаментной плите: скрин раздела сметы, нужные листы PDF, небольшие текстовые пояснения;
- не класть сюда весь проект или всю смету, если для анализа нужен только один раздел.
