# 2026-05-22 Flat Roof

Папка для новой расшифровки созвона по разделу:

```text
Плоская кровля
```

## Что положить сюда

Расшифровку встречи:

```text
transcript.txt
```

или исходный файл, если расшифровка пришла в другом формате:

```text
transcript.docx
transcript.pdf
```

Скриншоты / примеры из сметы или PDF складывать в:

```text
examples/
```

## Назначение

После добавления расшифровки эта папка используется для meeting analysis:

- извлечь правила Елены;
- выписать формулы и ручные места;
- зафиксировать открытые вопросы;
- подготовить основу для будущего калькулятора раздела плоской кровли.

## Важно

- AI может анализировать расшифровку и помогать извлекать правила.
- Смету должен считать детерминированный Python-калькулятор.
- Клиентская часть сметы пока не считается.
