# Notes: Flat Roof Calculator

- Калькулятор считает только серую внутреннюю себестоимость.
- Клиентская часть не считается.
- Белая зона Excel / клиентская зона находится вне текущего scope.
- Плоская кровля требует ручной проверки площади: проектная спецификация и расчётная площадь могут расходиться.
- `supplier_required_volume_m3` для ЭППС 50 мм и SLOPE плит — ручной ввод от поставщика / Технониколь.
- `roof_work_coeff` — параметр проекта, не постоянная величина.
- `price_code` нужен для будущей связки с Google Sheets `price_registry`.
- Не использовать Excel cell references в коде, README, notes или JSON.
- Строка временной двери не включена: это индивидуальная case-specific позиция.
- Строка "Логистика, и снабжение" включена как manual fixed material line по уточнению; база формулы будет разобрана отдельно.
- Строка "Технический надзор" включена как manual fixed work line по уточнению.
- Строка "Заготовительно-складские расходы" включена как manual fixed work line по сверке с серой зоной.
- Расходные материалы временно используют предоставленный raw total; base formula to be confirmed later.
- Нулевые строки структуры сохраняются для будущего Excel export и не влияют на internal totals.
