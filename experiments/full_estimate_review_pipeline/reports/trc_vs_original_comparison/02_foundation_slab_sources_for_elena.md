## Что из проекта, а что вручную/по умолчанию

**Из проекта (спецификация PDF):** площадь опалубки отбортовки (17.355 м², спец. страница
«Контрольные площади фундамента»), площадь мембраны PLANTER (183.88 м², стр.7), объём ЭППС 50мм
под плитой (7.994 м³), длина термовставок (7.15 мп, стр.20), объём бетона по зонам (45.58 м³,
сумма 2 зон), сама спецификация арматуры по позициям (диаметры и длины).

**Реально ручные поля — Елена/менеджер вводит каждый раз заново, формулы для них нет:**
объём миксера бетона (влияет на число рейсов доставки, типично 9 м³, но подтверждать нужно
каждый проект — у АРК, например, реально 7), количество смен крана и количество смен насоса
(формулы для числа смен нет ни в одном из 3 проектов — это решение по факту на площадке).

**Зашитые в коде константы — технически их можно поменять, но по проекту их никто не трогает,
для всех проектов используется одно и то же значение:** запас на фанеру и арматуру (5%), запас
на бетон (5%), запас на ЭППС/термовставки (5%), толщина пиломатериала для расчёта объёма доски
(0.05м — это не запас, а физический размер доски), объём пачки Пеноплэкс ГЕО (0.2776 м³ —
каталожная упаковка), шаг округления заказа бетона (0.5 м³), нормативы логистики (2%) и
расходных материалов (3%). Сумма технадзора берётся из прайс-реестра как обычная цена, ручной
ввод — только если в реестре её нет.

**Вручную поправлено конкретно по этому проекту:** подача арматуры краном обнулена (кран не
нужен для этого раздела); цены бетона/доставки/насоса — временное среднее по 2 проектам (ТРЦ и
АРК) до появления зонного механизма цен, реальные ставки Елены пока не совпадают ни с одной
зоной актуального прайса напрямую.

## Особый случай: почему монтаж/демонтаж опалубки стоят 0 ₽

Проверила реальные сметы ТРЦ, АРК, ЮСВ. У ТРЦ (и у нас) — деревянная опалубка, монтаж и демонтаж
идут отдельными строками с нулевой ставкой: реальная стоимость этой работы зашита внутри ставки
бетонирования (12000₽/м³ — та же ставка, что использует ЮСВ для одной объединённой строки
«монтаж опалубки + армирование + бетонирование + демонтаж»). У АРК — другая технология (щитовая
многоразовая опалубка), там монтаж и демонтаж — отдельные ненулевые строки. Наш ноль верен для
проектов с деревянной опалубкой (как ТРЦ), но был бы неправильным для проекта со щитовой
опалубкой — сейчас переключателя между этими двумя случаями в системе нет.
