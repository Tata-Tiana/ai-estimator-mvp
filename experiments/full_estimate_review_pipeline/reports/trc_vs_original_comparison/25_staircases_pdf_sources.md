Готовых итогов площади опалубки, количества ступеней, количества площадок и длины
штробления на листе нет. Елена добавит все четыре параметра в спецификацию.

Условная проверка закупки по правилам ТРЦ, ещё не принятым как универсальные:

```text
A500 d12: 256,0 x1,05 = 268,8 -> 23x11,7 = 269,1 м
A500 d16:   5,4 x1,05 =   5,67 -> 1x11,7 = 11,7 м
A240 d6:   16,8 x1,05 =  17,64 -> 3x6 = 18,0 м
Итого закупочная длина арматуры: 298,8 м
Бетон: 2,3 x1,05 = 2,415 -> 3 м3
```

Эти числа нужны только для проверки будущего калькулятора после ответов ST6/ST8.
Они не должны попадать в текущую смету НВД3, потому что лестничный раздел там выключен.

Проверка всех 373 строк и 268 столбцов листа `НС 17.09.26` не нашла лестничного блока
или переноса указанных количеств в соседний раздел. Производственный сценарий:

```text
parser: found_in_project=true
review: сохраняет Л-1, источники и missing fields
estimator: included_in_estimate=false
export: блок лестницы отсутствует
```

НВД3 является положительным fixture для парсера и переключателя раздела, но не эталоном
порядка строк, ставок или формул. Для этих целей главным эталоном остаётся ТРЦ.

## Почему Полностью Автоматический Обмер Пока Ненадёжен

По структуре источников парсер сможет надёжно определить две конструкции ТРЦ и одну Л-1
НВД3 по заголовкам, а также извлечь табличные бетон и арматуру. Керамзит и кирпич
текущего PDF игнорируются как материалы отделочного этапа. В старых спецификациях четыре
денежно значимых входа отсутствуют как готовые числа:

- площадь опалубки;
- количество ступеней;
- количество площадок;
- длина штробления под площадку.

Восстановление 38,1485 м2 по разнесённым размерам и граням чертежа повторяет ручной
инженерный обмер Елены. Это не должно становиться обязательной production-задачей модели.
После исправления спецификаций опалубка, ступени, площадки и штробление извлекаются
только как готовые поля. До исправления они имеют статус `missing_spec_data`,
а не рассчитываются моделью по картинке.

## Динамическая Модель

Технически раздел строится тем же способом, что плиты:

```text
staircase_zones[]
  staircase_id
  display_name
  staircase_kind
  source_order
  found_in_project
  project_data_status
  formwork_area_m2
  chasing_length_m
  steps_count
  landings_count
  concrete_class
  concrete_spec_volume_m3
  pour_batch_id
  included_in_estimate

staircase_rebar_items[]
  staircase_id
  position / purpose
  steel_class
  diameter_mm
  spec_length_m
  kg_per_meter

staircase_additional_material_items[]
  staircase_id
  material_name
  quantity
  unit
  included_as_line
```

Количество блоков в итоговой смете равно количеству подтверждённых строк
`staircase_zones[]` с `included_in_estimate=true`. Порядок берётся из проекта/спецификаций,
не из зашитого списка Л-1/Л-2.

Парсер устанавливает только факт и полноту проектных данных. Переключатель
`included_in_estimate` принадлежит сметчику: парсер не должен угадывать договор по PDF.

Для каждой зоны калькулятор вызывается независимо, как `floor_slabs` вызывает расчёт
на каждую физическую заливку. Результат хранит массив блоков, например:

```json
{
  "section": "monolithic_staircases",
  "staircases": [
    {"title": "Л-1", "estimate_lines": []},
    {"title": "Л-2", "estimate_lines": []}
  ]
}
```

## Правило Формирования Строк Блока

Один жёсткий шаблон нельзя копировать целиком, потому что Л-1 и Л-2 различаются.
Нужен стабильный порядок с условными ролями:

1. Штробление, только если оно подтверждено для лестницы.
2. Монтаж опалубки.
3. Фанера.
4. Пиломатериал.
5. Изготовление/монтаж армокаркаса.
6. Арматура по диаметрам от большего к меньшему.
7. Бетонирование площадок, если `landings_count>0`.
8. Бетонирование ступеней, если `steps_count>0`.
9. Бетон.
10. Доставка.
11. Насос или ручная подача по явным организационным полям.
12. Согласованные дополнительные материалы текущего конструктивного этапа; керамзит
    и кирпич отделочного этапа сюда не входят.
13. Логистика, расходники и четыре структурные строки.
14. Итог блока.

Нулевые/пустые строки, присутствующие в выбранной схеме Елены, сохраняются.
Но строка, которой у Елены нет в конкретном типе блока, не добавляется автоматически
как новый ноль: например, Л-2 не получает площадки и штробление только потому, что они есть у Л-1.

## Parser Gate И Защита От Дублей

Создание `staircase_zones` разрешено только при явной марке/заголовке лестницы
и собственной спецификации либо при ручном подтверждении в review.

Негативные контексты/маршрутизация:

| Текст проекта | Владелец |
|---|---|
| «Плита перекрытия лестницы» | `floor_slabs` |
| «Кровля лестницы» | `flat_roof` |
| «Выпуски под/в лестницу» без отдельной спецификации | исходная конструкция/диагностика |
| «Лестница Л-1», отдельная ведомость | `monolithic_staircases` |

Дедупликация идёт по нормализованной марке + ссылке на таблицу/лист, а не по любому
совпадению слова. Если обязательные поля отсутствуют, статус `present_missing_data`.
Он блокирует расчёт только включённого раздела; при `included_in_estimate=false` данные
остаются в review, а нулевой блок сметы не создаётся.

## АРК И ЮСВ

В доступных эталонных Excel АРК/ЮСВ отдельные строки лестниц/маршей/ступеней не найдены.
Текстовый слой четырёх PDF также не дал таких совпадений.

Это используется только как регрессионная проверка: новый раздел не должен появиться
по ошибке. Отсутствие текстового совпадения не доказывает конструктивное отсутствие,
поэтому АРК/ЮСВ нельзя превращать в универсальное правило «лестниц нет» без статуса
комплектности проекта.

## Что Установлено И Что Требует Ответа

Установлено:

- ТРЦ содержит две самостоятельные монолитные лестничные конструкции.
- Их марки/бетон/арматура извлекаются таблично и разделяются надёжно.
- Динамический N-блочный раздел архитектурно совместим с существующим pipeline.
- Лестничная плита не входит в новый модуль.
- НВД3 содержит Л-1 в проекте, но не содержит лестничного раздела в смете.
- Наличие в проекте и включение в смету должны управляться независимо.

Не установлено:

- закупочные округления фанеры/доски, бетон/доставка и работа армокаркаса;
- общая или раздельная поставка бетона для нескольких лестниц;
- владение 36 м выпусков A500 d12;
- ставки/проценты и смысл пустых структурных строк.

Установлено дополнительно: опалубка, ступени, площадки и штробление должны приходить
готовыми значениями спецификации; керамзит и кирпич Л-2 исключены как материалы отделки.

Вопросы и требуемые дополнения спецификаций вынесены в отчёт 26.
