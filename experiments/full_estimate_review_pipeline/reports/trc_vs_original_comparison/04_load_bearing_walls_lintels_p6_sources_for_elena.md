## Что из проекта, а что вручную/по умолчанию

**Из проекта (спецификация PDF, стр.8/11/12):** объёмы блоков по типу и этажу, длины и объёмы
бетона перемычек (U-блок и монолит по каждой марке), площади опалубки перемычек, объём ЭППС
утепления, вся спецификация арматуры по позициям (кладка, парапет, перемычки), площадь отсечной
гидроизоляции (посчитана суммой наружных+внутренних по правилу Елены, готовой цифры в PDF нет).

**Реально ручные поля — формулы для них нет:** комплекты лесов/подмостей и объём пиломатериала для
лесов (лист 01-1, типовое значение 2/2 — подтверждать по каждому проекту, см. выше). Доставка
металла приходит с уровня коробки (box-калькулятор), технадзор — фиксированная сумма.

**Зашитые в коде константы, одинаковые для всех проектов:** запас на блок/клей/арматуру/бетон/ЭППС
(5%), объём паллеты по типу блока (D400 — 2.15 м³, D500 — 1.8 м³), вместимость машины доставки
(32 м³), длина прутка арматуры (11.7м для Ø10-25, 6м для Ø6), расход клея (1.2 мешка/м³), расход
пескобетона (19 кг/м²/10мм × коэфф. 2), толщина доски опалубки (0.05м), толщина сечения перемычки
для расчёта утепления (0.25м), объём пачки ЭППС (0.2773 м³), минимальный заказ бетона на зону
(1 м³), 3 смены на вывоз мусора, ставка технадзора (10000₽), норматив расходных материалов (3%).

**Открытые вопросы (не код-баги)** — см. отдельные сообщения Елене: минимальная партия
пиломатериала на опалубку перемычки; объём блока 2 этажа (возможно проект пересматривался после
расчёта сметы); единица ценообразования бетонирования монолитной перемычки 2 этажа (мп у нас vs
м³ у Елены — прайс-лист Елены задаёт обе позиции в мп, наш подход соответствует её же прайсу).
