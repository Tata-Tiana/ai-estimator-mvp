# Общий заказ блоков с переносом остатка между этапами

Реализовано 2026-09-18 по задаче Елены и подтверждённому пользователем варианту.
Актуальный контрольный проект: АРК, исходные входные данные сметы `160829`
из `chat_extraction_poc/outputs/extraction_output_7_20260910_131118/section_results`.
Данные и группировка логистики ЮСВ не исправлялись; специальных правил по проектам нет.

## Правило

Для одинакового материала накапливается проектный объём по зонам в порядке этапов
`wall_zones[]`, после объединения подзон парапета. Применяется запас 1.05.

```text
накопленные поддоны = ceil(накопленный проектный объём * запас / объём поддона)
новые поддоны этапа = накопленные поддоны - ранее заказанные поддоны
закупка существующей строки этапа = новые поддоны этапа * объём поддона
```

Количество поддонов по всему материалу равно округлению одной общей потребности.
Материалы группируются по нормализованной плотности и всем трём размерам;
порядок записи размеров не влияет на группировку. Разная длина изделий не объединяется.
При несовпадении цены либо объёма поддона одного материала расчёт выдаёт явную ошибку.

Существующие коды, названия и порядок строк сохраняются. Новых строк закупки нет.
Общие итоги находятся только в контрольных данных `calculation_blocks.block_purchase_pools`.
Если этап покрывается остатком, строка закупки сохраняется с количеством 0;
кладка и клей продолжают считаться по проектной потребности.

## Доставка и кран

Партии не объединяются заново. Доставка и разгрузка считаются по новым закупкам этапов.
Строки партии сохраняются с количеством 0, если вся потребность покрывается прежним остатком.

Кран учитывает не только новую закупку, но и подъём ранее купленного блока:
объём подъёма зоны = max(новая закупка, проектный объём * запас).
Для положительного объёма сохраняется минимум одна смена в соответствующей группе крана.
`crane_batches.block_order_volume_m3` описывает новые закупки;
`block_lift_volume_m3` описывает базу расчёта смен. Отдельный подъём парапета сохранён.

В АРК доставка остаётся 4 + 2 машины, разгрузка 4 + 2, кран 2 + 1 + 1 смены.
Вторая поставка уменьшается с 42.65 до 40.50 м3, но не пересекает порог количества машин.
