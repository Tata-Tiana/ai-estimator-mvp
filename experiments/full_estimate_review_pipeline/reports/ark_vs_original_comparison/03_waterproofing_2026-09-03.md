## ⚠️ Главное: разделы не сопоставимы напрямую — разный охват по АРК

У ТРЦ и ЮСВ этот раздел называется просто «ГИДРОИЗОЛЯЦИЯ, УТЕПЛЕНИЕ БОРТОВ ПЛИТ» и покрывает только
саму плиту. У АРК раздел называется **«...РОСТВЕРКА И БОРТОВ ПЛИТЫ»** — то есть Елена по этому
конкретному проекту объединила в одну строку гидроизоляцию ростверка (у нас этот раздел вообще не
считается, см. отчёт 02 и открытый вопрос по ростверку) и гидроизоляцию самой плиты.

Проверила все три проекта по площади из этой первой строки раздела (мастика):

| Проект | Название раздела | Площадь мастики, м² |
|---|---|---:|
| ТРЦ | ...БОРТОВ ПЛИТ (только плита) | 16,77 |
| ЮСВ | ...БОРТОВ ПЛИТ (только плита) | 24,30 |
| АРК | ...**РОСТВЕРКА** И БОРТОВ ПЛИТЫ (плита + ростверк) | **187,41** |

У ТРЦ/ЮСВ эта площадь примерно совпадает с их же площадью опалубки отбортовки плиты (тот же паттерн
«одна и та же цифра используется и для опалубки, и для гидроизоляции» — уже видели в отчёте 02).
У АРК 187,41 м² — это в разы больше, чем даже готовая PDF-площадь «под гидроизоляцию» (46,5 м²,
такая же строка, что была для опалубки, отчёт 02 находка №1), не говоря уже про её собственный
пересчёт площади плиты (27,2 м², если по аналогии с опалубкой). Разница (187,41 − ~27 ≈ 160 м²)
примерно совпадает по порядку величины с `foundation_wall_items.waterproofing_coating_area_m2`
(163,0 м² — площадь гидроизоляции стен ростверка по нашему извлечению) — то есть похоже, что
187,41 = гидроизоляция ростверка (~163) + гидроизоляция самой плиты (~24-27), просто объединены в
одну строку именно у АРК.

**Вывод: прямое построчное сравнение сумм для АРК вводит в заблуждение — почти вся разница объясняется

## Что можно проверить чисто (сопоставив ТРЦ/ЮСВ вместо АРК)

Поскольку у ТРЦ и ЮСВ раздел «чистый» (только плита, без ростверка), для проверки самой ФОРМУЛЫ
(а не абсолютных чисел под конкретный проект) лучше смотреть на них:

| Проект | Площадь мастики = площадь опалубки? | Утепление ЭППС 100мм площадь |
|---|---|---:|
| ТРЦ | 16,77 (мастика) vs 16,38 (опалубка) — близко, не тождественно | 16,77 м² |
| ЮСВ | 24,30 (мастика) vs 24,30 (опалубка) — точное совпадение | 17,5 м² (меньше площади мастики — не всё покрытие утепляется) |

То есть даже у «чистых» ТРЦ/ЮСВ формула не универсальна: где-то мастика = опалубка ровно, где-то
почти, утепление ЭППС может быть меньше площади мастики (не вся гидроизолированная поверхность
утеплена). Это подтверждает то же, что уже знаем с отчёта 02: она использует свой собственный
пересчёт геометрии плиты, а не готовую PDF-площадь — универсальной формулы, которую можно было бы
просто зашить в код, пока не видно.

## Итог

Этот раздел по АРК нельзя честно сравнить построчно с нашей сметой — Елена объединила в него
гидроизоляцию ростверка (у нас не считается вообще, известный открытый вопрос) с гидроизоляцией
самой плиты. Единственное чистое совпадение — «Технический надзор» (0₽ у обеих сторон). Реальная
проверка формулы гидроизоляции самой плиты возможна только на ТРЦ/ЮСВ (где раздел не смешан с
ростверком) — и там видно, что формула не единая (иногда мастика=опалубка точно, иногда почти,
утепление ЭППС может быть меньше площади мастики). Нужно решать вопрос ростверка в целом (уже в
открытых вопросах) — до этого предметно сравнивать эту строку по АРК бессмысленно.
