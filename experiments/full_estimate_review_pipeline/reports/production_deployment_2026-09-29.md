## Telegram-прокси

Техподдержка сообщила, что для Telegram из РФ следует использовать HTTP или MTP.
Выданный endpoint проверен с клиентского сервера как HTTP-прокси: Telegram API
доступен, метод `getMe` вернул `ok=true`. Как SOCKS5 этот endpoint не используется.
Логины и пароли в отчёт и журналы не выводились.

Production-конфигурация содержит `TELEGRAM_PROXY_SCHEME=http`; реквизиты находятся
только в закрытом `calc.env`. Ручной параллельный запуск запрещён.
