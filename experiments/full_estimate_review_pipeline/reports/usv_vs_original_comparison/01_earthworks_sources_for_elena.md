## Что из проекта, а что вручную/по умолчанию

**Из проекта (спецификация PDF):** площадь котлована (322.5 м², используется частично — см. ниже),
площадь геотекстиля (320 м²), объём песка под основание (96.6 м³), длины маршрутов траншей
(К1/К2/водопровод/электрокабель), длина входов коммуникаций (115 мп).

**Ручные поля (лист 01-1, можно менять под проект):** глубина котлована (0.5м — используется и для
смен экскаватора, и как база для доработки дна), глубина ручной доработки дна (0.08м), коэффициенты
глубины траншей по типу сети (К1=0.2, К2=0.2, водопровод=1.6, электрокабель=0.6), коэффициент
нахлеста геотекстиля (1.1), запас песка (0 для этого проекта), норматив расходных материалов (3%).

**Вручную поправлено конкретно по этому проекту (лист 01, поверх найденного):** площадь укладки
геотекстиля (340 м² вместо готовой строки спецификации 320 м² — Елена считает по своей геометрии
котлована, не по спецификации); запас песка на листе 01-1 (0 вместо справочного значения 20 — в
реальной формуле Елены для этого проекта резерв не прибавляется).
