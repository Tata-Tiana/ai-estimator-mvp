# Step 29. Доставка бетона, бетононасос и кран: план разборки

## Будущий Охват 2026-09-18

План полной коробки включает самостоятельный армопояс и группу скатной кровли из
пяти расчётных модулей, визуально отдельных разделов: [шаг 30](step_30_grillage_full_box_scenario.md).
При их реализации проверить отдельные партии/этапы доставки и ручные смены техники.
Бетон армопояса не включать молча в бетон других конструкций; логистику скатной кровли
не переносить автоматически из плоской. Правила новых модулей ещё не согласованы.

Дата: 2026-08-11

Статус: план / вернуться позже.

## Зачем эта заметка

На листе `01-1` и в смете есть три похожие, но разные логистические позиции:

- доставка бетона;
- работа бетононасоса;
- подача опалубки/арматуры краном.

Они выглядят как “раз бетон/арматура есть, значит строка должна быть везде”, но по реальным сметам АРК, ТРЦ и ЮСВ это не одна логика. Надо не смешать автоматический расчет с ручными сменами.

## Что видно по трем сметам

### Доставка бетона

Это расчетная строка. В сметах она считается от объема заказанного бетона и объема миксера:

`количество рейсов = округлить вверх(объем бетона к заказу / объем миксера)`

Что важно:

- в ТРЦ обычно используется миксер `9 м3`;
- в ЮСВ обычно используется миксер `9 м3`;
- в АРК встречается миксер `7 м3`.

Вывод: доставку бетона можно и нужно считать автоматически там, где есть бетон. Но объем миксера нельзя тихо хардкодить один на все проекты. Он должен быть видимым/проверяемым параметром.

### Работа бетононасоса

Это не расчет от объема бетона. В сметах это ручная смена, чаще всего `1 смена`.

Что видно:

- фундаментная плита: бетононасос есть во всех трех сметах;
- плиты перекрытия: бетононасос есть по каждой плите/заливке;
- стены/перемычки: обычно есть доставка бетона и иногда ручной перенос/подъем бетона, но не отдельный бетононасос.

Также различается тип/цена насоса:

- ТРЦ: фундамент и плита 1 этажа — 28 м, плита 2 этажа/лестница — 36 м;
- АРК: фундамент — 36 м, плиты — 40 м;
- ЮСВ: в актуальном листе — 32 м.

Вывод: бетононасос нельзя автоматически ставить везде, где есть бетон. Его надо показывать как ручное/проверяемое поле там, где по разделу он ожидается.

### Подача опалубки/арматуры краном

Это тоже не автоматическая доставка металла. Это смены крана для подачи опалубки и/или арматуры.

Что видно:

- фундаментная плита: есть во всех трех сметах, обычно `1 смена`;
- плиты перекрытия: есть по каждой плите, обычно `1` или `2 смены`;
- стены/перемычки: там чаще другая строка — перемещение блоков/смеси автокраном, а не подача арматуры;
- кровля: есть подъем материалов автокраном, это отдельная кровельная логика.

Вывод: кран нельзя считать от веса арматуры. Вес арматуры используется для доставки металла, но не для смен крана.

## Предварительная матрица по разделам

### Земляные работы

Этих трех строк нет.

### Фундаментная плита

Должно быть:

- доставка бетона — автоматом от заказанного бетона и объема миксера;
- бетононасос — ручное/проверяемое количество смен;
- подача арматуры краном — ручное/проверяемое количество смен;
- доставка арматуры/металла — отдельно, через box-калькулятор 10 т.

### Стены и перемычки

Должно быть аккуратно разделено:

- доставка бетона для перемычек — сейчас скорее ручная/поставочная, надо проверить возможность автоматизации от объема бетона перемычек;
- бетононасос обычно не нужен;
- кран для блоков/смеси — отдельная строка раздела стен;
- подача арматуры краном как в плитах/фундаменте не подтверждена реальными сметами;
- доставка арматуры/металла — уже надо учитывать через box-калькулятор, даже если в трех образцовых сметах машина на стенах не появилась.

### Плиты перекрытий

По каждой реальной плите/заливке должно быть:

- доставка бетона — автоматом от бетона этой плиты и объема миксера;
- бетононасос — ручное/проверяемое количество смен;
- подача опалубки/арматуры краном — ручное/проверяемое количество смен;
- доставка арматуры/металла — через box-калькулятор по накоплению поставочного веса.

### Кровля

Бетонных строк нет. Есть отдельная строка:

- подъем материалов автокраном.

Ее не смешивать с подачей арматуры/опалубки и не связывать с весом арматуры.

### Вентканалы

Есть своя доставка вентканалов. Эти три строки не применяются.

## Что надо сделать позже

1. Проверить контракты и калькуляторы по всем разделам:
   - где доставка бетона уже считается автоматически;
   - где доставка бетона сейчас ручная, но должна считаться от объема;
   - где бетононасос должен быть ручным полем;
   - где кран должен быть ручным полем.

2. Для доставки бетона привести пояснения к человеческому виду:
   - объем бетона к заказу;
   - объем миксера;
   - формула округления;
   - итоговое количество рейсов.

3. Для бетононасоса и крана явно написать в листе проверки:
   - это ручная смена;
   - автоматической формулы нет;
   - проверьте `0/1/2` смены по смете/условиям работ.

4. Не использовать box-калькулятор для крана.

5. Не ставить бетононасос автоматически только потому, что есть бетон.

6. Разобраться отдельно со стенами/перемычками:
   - можно ли доставку бетона для перемычек считать так же, как в фундаменте/плитах;
   - должна ли там оставаться ручная строка;
   - как это совпадает с АРК, ТРЦ и ЮСВ.

## Текущее рабочее решение до отдельной правки

- Доставка арматуры/металла считается через box-калькулятор по поставочному весу арматуры.
- Кран остается ручным.
- Бетононасос остается ручным.
- Доставка бетона считается автоматически только там, где это уже реализовано калькулятором.
