# Vent-channel shaft masonry gas block (D400 150x250x650) — real АРК finding, 2026-07-26

Based on the same real АРК project as `test_schiedel_vent_channels_ark` (masonry length 5.43 м.п.,
3х/4х channel counts — reused here unchanged), extended with `schiedel_masonry_gas_block_items`.

## Источник и статус

АРК КР2 стр. 25 ("Схема расположения шахт вентканалов"), спецификация «СПЕЦИФИКАЦИЯ МАТЕРИАЛОВ НА
УСТРОЙСТВО ВЕНТКАНАЛОВ»: «блок 150х250х650, D400: 1,6м3». Подпись плотности D400 повторяется 6+ раз
на листе (ШВ-1…ШВ-4, типовые сечения) — не разовая опечатка.

Изначально (план, раздел 7, 2026-07-23) эта находка была ошибочно классифицирована как противоречие
финализированному правилу D400/D500 для стеновой семьи блоков (600×400×250/600×250×250). Переисследовано
2026-07-26 (план, раздел 28.3): это ДРУГОЙ блок в ДРУГОМ калькуляторе — кладка самой шахты вентканала
Schiedel, не обкладка дымохода (`vent_chimney_cladding` в `load_bearing_walls_lintels_calculator.py`,
600×150×250, жёстко D500, уже сверено с реальной сметой). Правило стеновой семьи не трогается, оно про
другую номенклатуру.

## Важное — цена материала условная, не из реальной сметы

Реальная смета АРК **не содержит** отдельной ценовой строки для этого газобетонного блока вообще (в
разделе «ВЕНТИЛЯЦИОННЫЕ КАНАЛЫ Schiedel» есть только работа «Кладка вентканалов Schiedel» и штучные
блоки самого Schiedel — 3х/4х) — то есть материал сегодня физически не костится нигде, это и есть сам
пробел, который эта правка закрывает. `schiedel_masonry_gas_block_d400_unit_price = 7500` в этом кейсе —
представительная тестовая цена (не из смет), проверяющая механизм расчёта, а не воспроизводящая
конкретную сумму реального проекта.

## Что проверяет кейс

- `schiedel_masonry_gas_block_items` — аддитивный опциональный список `{density, volume_m3}`; при
  отсутствии (как во всех трёх старых кейсах) поведение побайтово не меняется.
- Плотность берётся как есть из PDF (`D400` в этом кейсе), без эвристики по ширине блока — если бы в
  проекте был указан D500, взялся бы `schiedel_masonry_gas_block_d500_unit_price`/price_code
  `schiedel_masonry_gas_block_d500_m3` без каких-либо изменений кода.
- Объём суммируется по плотности (тот же паттерн бакетирования, что и `schiedel_channel_items`), новая
  строка материала попадает в `direct_cost_base_before_consumables` и, соответственно, в расходные
  материалы/амортизацию инструмента (3%).
