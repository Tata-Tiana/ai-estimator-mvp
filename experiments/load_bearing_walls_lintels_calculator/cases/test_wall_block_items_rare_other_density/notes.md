# Редкий блок не D400/D500 (Елена, 2026-07-28)

Вопрос: «D400 = 600×400×250 (наружные стены), D500 = 600×250×250 (внутренние стены). Другого
размера у этих плотностей не бывает. Это правильно?» — Елена: «Могут [быть другие размеры], но
очень редко».

Кейс построен на базе `test_scaffolding_from_wall_block_items` (те же числа для main_walls/
parapet), но у floor_2 плотность заменена с D400 на условный «D350, 600x350x250» с явной ценой
`material_unit_price: 6800` — floor_2 целиком построен из редкого блока, без грамма D400/D500.

## Что проверяет кейс

- **Валидация** — `block_density`, отличный от D400/D500, разрешён, если явно дана
  `material_unit_price` на этой же строке (иначе `ValueError`, см. негативный кейс-пару
  `test_wall_block_items_rare_density_missing_price_rejected`).
- **`floor_2_load_bearing_walls.enabled = true`** — floor_2 корректно определяется как
  существующий раздел, хотя в нём нет ни капли D400/D500 (раньше гейт смотрел только на D400).
- **`floor_2_total_masonry_volume_m3 = 12.5`** — объём редкого блока попадает в общий объём кладки
  наравне с D400/D500 (работа кладки не зависит от плотности, только материал).
- **Леса на 2 яруса** (`scaffolding.floors_count = 2`, `floors_count_source = "wall_block_items"`,
  несмотря на `floors_count_input = 1` — заведомо неверное легаси-значение) — тот самый риск,
  который обсуждали: раньше леса ловили второй этаж только по D400, теперь — по любому объёму
  `floor_2`, любой плотности.
- **`wall_block_other_floor_2_4`** — новая ценовая строка, цена берётся прямо из
  `material_unit_price` данной строки (6800), без округления по поддонам (это не стандартный SKU,
  пакетный объём для него неизвестен).
- **D400/D500 у main_walls и parapet в этом же кейсе не тронуты** — доказывает, что обычный путь
  полностью независим от редкого.

Числа условные (не из реального проекта) — Елена не дала конкретных подробностей по редкому
случаю, только подтвердила, что он бывает. Проверяет механизм, не конкретную PDF-находку.

Полный прогон: 23/23 позитивных кейса (был 22, этот кейс новый), 0 расхождений.
