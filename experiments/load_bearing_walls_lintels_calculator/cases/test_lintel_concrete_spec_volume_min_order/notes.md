# Lintel Concrete Spec Volume Min Order

Production-кейс для минимального заказа бетона перемычек.

Входной проектный объём:

```text
lintel_concrete_spec_volume_m3 = 0.38
```

Минимальный закупочный объём является default:

```text
lintel_concrete_min_order_volume_m3 = 1.0
```

В input это поле не передаётся, калькулятор подставляет default.
