# Позитивный кейс: подоконное армирование с явным уникальным code — коллизии нет

Пара к `test_main_wall_rebar_duplicate_line_code_rejected` — доказывает, что рекомендованный выход из
коллизии (явный уникальный `code` на одной из строк) действительно работает: обе строки (основная,
1070 м.пог, и "подоконная", 4,4 м.пог, обе floor=1/load_bearing_walls/A500/Ø10) сохраняются раздельно
в `controls`/`estimate_lines`, и агрегаты (`main_wall_rebar_base_length_m`/`order_length_m`/
`delivery_weight_kg`) корректно суммируют ОБЕ строки (1070+4,4=1074,4 м базовой длины), а не теряют
одну из них.

Числа условные (не из конкретного реального проекта) — этот кейс проверяет механизм разрешения
коллизии, а не конкретную PDF-находку.
