# Внешние и внутренние несущие стены, перемычки

Считается только серая внутренняя себестоимость. Клиентская часть не считается.

## Постоянные правила

1. В раздел несущих стен входят блоки 400 мм и 250 мм.
2. Блоки 150 мм - это перегородки, по умолчанию не входят в коробку.
3. Работа по кладке считается от проектного объёма кладки без запаса 5%.
4. Материал газоблоков считается: объём из спецификации * 1.05 -> деление на объём поддона -> округление вверх -> обратно в м3.
5. Клей считается: `ceil(объём кладки * 1.2 * 1.05)`.
6. Пескобетон считается от площади гидроизоляции под первый ряд: `ceil(area * 19 * 2 / 40)`.
7. Гидроизоляция под первый ряд считается: длины стен 400 мм * 0.4 + длины стен 250 мм * 0.25.
8. Перемычки: суммарная длина перемычек / 0.6 = количество блоков на резку.
9. Бетонирование перемычек - работа по м.п. перемычек.
10. Бетон перемычек: длина * 0.125 * 0.125 * 1.05, но минимум 1 м3.
11. Арматура считается через: масса или базовая длина -> запас 5% -> целые прутки -> закупочная длина -> стоимость.
12. Штробление в серой части нулевое, но его длина используется как база для арматуры.
13. Доставка блоков считается от суммарного закупочного объёма газоблоков / 32 м3.
14. Разгрузка манипулятором равна количеству доставок блоков.
15. Краны - fixed/manual по сменам.

## Парапет

1. Парапет - постоянный блок.
2. Кладка над кухней / второй свет - не постоянный блок, а case_specific addon текущего проекта.
3. Для текущего проекта `second_light_masonry_enabled = true`, чтобы совпасть с Excel.
4. В других проектах `second_light_masonry_enabled` может быть false.
5. Материал D400 для парапета и второго света в текущем кейсе считается объединённо, чтобы не перезакладывать лишний поддон.
6. Клей для текущего кейса считается двумя группами:
   - second_light отдельно;
   - parapet + vent/chimney вместе.
   Это нужно для совпадения с Excel.
7. Для универсальной логики калькулятора парапета основной объём - `parapet_masonry_volume_m3`.
