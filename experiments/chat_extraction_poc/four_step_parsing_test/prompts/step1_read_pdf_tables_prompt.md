# Шаг 1 — прочитать PDF и выписать таблицы проекта

Используй этот промпт в отдельном чате. В этот чат загружается только один PDF
проекта: либо КР1 / ниже нуля, либо КР2 / выше нуля.

Не загружай в этот чат:

- `calculator_targets_compact.json`;
- `target_aliases_ru.yaml`;
- `section_guide.json`;
- `unit_normalization_guide.json`;
- финальную schema extraction.

На этом шаге нельзя думать о смете, `target_code` и калькуляторах. Твоя задача —
сделать честную машиночитаемую перепись проекта.

## Что нужно сделать

1. Пройти PDF постранично.
2. Для каждой страницы определить:
   - номер страницы PDF;
   - номер листа из штампа, если виден;
   - общее количество листов из штампа, если видно;
   - название листа;
   - короткий сырой текст штампа/титула.
3. Выписать все таблицы, спецификации, ведомости и табличные блоки подряд.
4. Сохранять колонки как они видны в проекте. Не перепридумывать заголовки.
5. Сохранять исходные ячейки и `raw_text`.
6. Если строка различается только графическим маркером, штриховкой, цветом или
   обозначением в первой колонке, сохранить этот маркер и дать ссылку на легенду
   через `legend_ref`.
7. Если таблица нечитаема или колонки разъехались, не угадывать: сохранить как
   получилось и добавить предупреждение.

## Правило про штампы

Адрес проекта определяется по титульному листу / загруженному комплекту. Штампы
отдельных листов могут быть ошибками оформления: проектировщики часто копируют
листы из других проектов и не правят адрес/шифр. Не отбрасывай страницу только
из-за другого штампа.

Если штамп отличается от титульного:

- запиши это в `page_map[].stamp_discrepancy_note`;
- добавь общее предупреждение в `extraction_warnings`;
- продолжай выписывать таблицы этой страницы по содержанию.

## Формат ответа

Верни только JSON без markdown-обертки:

```json
{
  "step": "step1_project_tables",
  "source_pdf": "<имя PDF>",
  "project_from_title": {
    "name": null,
    "address": null,
    "project_code": null,
    "cadastre_number": null,
    "raw_text": null
  },
  "page_map": [
    {
      "page_number": 1,
      "sheet_number": null,
      "sheets_total": null,
      "page_title": null,
      "title_block_raw_text": null,

  "raw_table_rows": [
    {
      "row_id": "<source_pdf>:p<page_number>:t<table_index>:r<row_index>",
      "source_pdf": "<имя PDF>",

```

## `legend_ref`

Если строка таблицы ссылается на легенду через штриховку/маркер, пиши:

```json
"legend_ref": {
  "marker_raw": "<штриховка диагональная>",
  "legend_text": "Несущие стены",
  "legend_source": "PDF page <page_number>, лист <sheet_number>: легенда схемы"
}
```

`page_number` и `sheet_number` всегда бери из текущего проекта/листа. Не копируй
номер страницы из примера. Если легенды нет или маркер не нужен, ставь
`legend_ref: null`.

## Запреты

- Не создавай `target_code`.
- Не выбирай раздел сметы.
- Не суммируй строки, если в PDF нет строки "Итого".
- Не конвертируй единицы.
- Не исправляй ошибки проекта.
- Не сокращай таблицу до трех колонок, если в PDF колонок больше.
- Не теряй ГОСТ/СТО/марки материалов, если они есть в строке.
