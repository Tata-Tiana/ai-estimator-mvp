# Отчёт: арматура перегородок из спецификации в м.п.

Дата: 2026-06-10

## Статус

Отдельного калькулятора перегородок в проекте пока нет. В рамках этой задачи он не создавался.

## Правило

Арматура перегородок не должна попадать в калькулятор несущих стен и перемычек.

Для будущего раздела перегородок нужна такая же структура:

```text
floor
component = "partitions"
steel_class
diameter_mm
spec_length_m
kg_per_meter
rod_length_m
unit_price_per_m
```
