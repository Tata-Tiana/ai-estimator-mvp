## 1. Общая цель проекта

Проект `ai-estimator-mvp` — это MVP AI-сметчика для анализа проектной документации частных домов.

Идея проекта:

1. взять PDF-проект;
2. извлечь из него текст, таблицы и инженерные параметры;
3. собрать структурированную техническую карточку проекта;
4. на основе карточки перейти к расчёту сметы;
5. позже подключить API УНИКМА для номенклатуры, цен, остатков и сопоставления материалов.

Текущий фокус:

- не расчёт стоимости;
- не коммерческая смета;
- а подготовка качественных входных данных для будущего расчёта.

## 2. Принцип организации проекта

Проект разделён на два уровня:

- `app/` — будущий рабочий код MVP;
- `experiments/` — экспериментальный и исследовательский контур.

Правило:

- всё временное, тестовое, исследовательское — в `experiments/`;
- всё, что потом станет стабильной частью MVP — переносится в `app/`.

- `combine_project_texts.py`

3. отправляет их в OpenAI;
4. получает структурированную техническую карточку проекта;
5. сохраняет результат в новую папку AI-прогона.

Формат результата AI-прогона:

- `full_text_combined.txt`
- `sources.json`
