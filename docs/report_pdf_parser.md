# Отчёт по PDF-парсеру

Дата: 2026-05-15

## Кратко

В проекте `ai-estimator-mvp` сделан экспериментальный PDF-парсер для проектной документации частных домов. Его задача - разбирать PDF проекта и сохранять данные в формате, пригодном для дальнейшего анализа: полный текст, текст по страницам, блоки с координатами, найденные таблицы и краткую сводку по файлу.

Парсер не считает смету сам. Он подготавливает исходные данные проекта, которые затем можно использовать для AI-карточки проекта и для ручной/автоматизированной подготовки входных параметров расчётных калькуляторов.

## Что реализовано

Реализован модуль:

```text
experiments/pdf_tests/pdf_parser.py
```

Реализован интерактивный запуск:

```text
experiments/pdf_tests/run_pdf_parser.py
```

Поддерживаются режимы:

- извлечение текста через PyMuPDF;
- извлечение текстовых блоков с координатами;
- извлечение таблиц через pdfplumber;
- полный прогон PDF: текст + блоки + таблицы + summary.

## Что сохраняется на выходе

Для каждого обработанного PDF создаётся папка результата с файлами:

```text
full_text.txt      - полный текст PDF
pages_text.json    - текст отдельно по страницам
blocks.json        - текстовые блоки с координатами
tables.json        - найденные таблицы в JSON
tables.xlsx        - найденные таблицы в Excel
summary.json       - краткая сводка по обработке PDF
```

## Организация по проектам

Введена структура хранения PDF-экспериментов по домам:

```text
experiments/pdf_tests/projects/<project_name>/
├── input/
├── output/
└── notes.md
```

Это удобнее старого формата в `data/output`, потому что все входы и результаты конкретного дома лежат рядом.

## Как это используется дальше

PDF-парсер нужен как первый технический слой:

1. Получить из проектной документации текст, таблицы и координатные блоки.
2. Сохранить результат в проверяемом виде.
3. Использовать эти данные для AI-карточки проекта и ручной проверки.
4. Передавать подтверждённые параметры в детерминированные калькуляторы сметы.

Принцип проекта: AI может помогать извлекать параметры из документации, но сами расчёты сметы выполняются обычным Python-кодом.

## Что уже хорошо работает

- PDF-файлы можно разбирать повторяемым способом.
- Результаты сохраняются в понятной структуре по домам.
- Таблицы выгружаются не только в JSON, но и в Excel.
- Для каждого PDF сохраняется `summary.json`, по которому быстро видно качество извлечения.

## Ограничения текущего этапа

- Парсер пока является экспериментальным модулем, а не финальным пользовательским интерфейсом.
- Качество извлечения зависит от качества PDF и структуры документа.
- После парсинга всё равно нужна проверка человеком: особенно для важных чисел, спецификаций и неоднозначных таблиц.

## Команда запуска

Из корня проекта:

```bash
.venv/bin/python3 experiments/pdf_tests/run_pdf_parser.py
```

Далее в меню выбирается режим обработки PDF.
