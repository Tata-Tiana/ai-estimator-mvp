# POC Excel-сметы с формулами: гидроизоляция

## Статус

Это изолированный POC, не production-интеграция.

Папка:

```text
experiments/excel_formula_poc_waterproofing/
```

Файл результата:

```text
experiments/excel_formula_poc_waterproofing/output/waterproofing_formula_demo.xlsx
```

## Зачем сделан

Цель POC — проверить, можно ли делать Excel-смету в привычном виде сметчиц, но с живыми обычными Excel-формулами в ячейках.

Формулы используются в формате A1:

```text
=P12*Q12
=J12*K12
=ROUNDUP(...)
=SUM(...)
```

Named ranges и технические Python-переменные в формулах не используются.

## Что внутри Excel

Видимый рабочий лист:

```text
Смета
```

Структура:

```text
A:I   — белая зона сметы
J:O   — серая внутренняя зона сметы
P:V   — правое серое вспомогательное поле
```

Белая зона технически копирует серую зону формулами:

```text
D12 = J12
E12 = K12
F12 = L12
G12 = M12
H12 = N12
I12 = O12
```

Клиентская часть не считается.

## Важное решение по правому полю

Правое поле `P:V` — это не отдельная панель и не прайс.

Оно сделано как построчное продолжение сметы: helper-значения стоят на той же строке, к которой относится строка сметы.

Примеры:

```text
строка гидроизоляции:
P12 = 81
Q12 = 0.3
R12 = P12*Q12
J12 = R12

строка праймера:
P13 = J12
Q13 = 0.3
R13 = 18
S13 = P13*Q13/R13
J13 = ROUNDUP(S13,0)

строка Пеноплэкса:
P16 = 0.2776
Q16 = J15*0.1*1.05
R16 = Q16/P16
J16 = ROUNDUP(R16,0)*P16
```

Для Пеноплэкса в `J16` хранится raw-количество, а отображение форматируется как `0.00`.
Сумма считается от raw, не от округлённого display.

Строки логистики, расходников и итоговая строка не дублируют helper-значения справа, потому что там нет отдельных параметров расчёта количества.

## Цены

Цены не вынесены в правое поле.

Они остаются в привычных колонках сметной таблицы:

```text
K — материалы / механизмы, за единицу
M — работы, за единицу
```

Для POC цены берутся из frozen fixtures.

## Источники

POC работает только от snapshot-файлов внутри своей папки:

```text
fixtures/input.json
fixtures/expected.json
fixtures/waterproofing_result.json
fixtures/price_registry_snapshot.xlsx
fixtures/brick_house_logo.png
```

Живые калькуляторы, `pricing`, `input_builder`, `pdf_parser_pipeline`, `calculation_runner` и demo app не читаются и не меняются.

## Вывод

Гипотеза рабочая: можно делать Excel в визуальном стиле сметчиц, где сметная таблица остаётся привычной, а справа находятся построчные helper-ячейки с проверочными формулами.
