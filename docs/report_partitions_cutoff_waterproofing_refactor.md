# Отчёт: отсечная гидроизоляция перегородок

Дата: 2026-06-09

## Статус

В проекте пока нет отдельного калькулятора перегородок. Полноценный новый модуль в этой задаче не создавался.

## Production-параметр

Для будущего раздела перегородок нужно использовать отдельный параметр:

```text
cutoff_waterproofing_partitions_area_m2
```

Смысл:

- готовая площадь отсечной гидроизоляции под перегородки;
- источник: спецификация проекта;
- не включает несущие стены;
- не должна попадать в `load_bearing_walls_lintels_calculator`.

## Классификация

| Параметр | Статус | Комментарий |
| --- | --- | --- |
| `cutoff_waterproofing_partitions_area_m2` | AUTO_PROJECT | Берётся готовой площадью из спецификации. |
