# Отчёт по калькулятору плоской кровли

Дата: 2026-05-26

## Кратко

В проекте `ai-estimator-mvp` сделан отдельный экспериментальный детерминированный калькулятор раздела:

`КРОВЕЛЬНОЕ ПОКРЫТИЕ ДОМА / плоская кровля`

Калькулятор считает только серую внутреннюю себестоимость: материалы/механизмы, работы и итог раздела. Клиентская часть, белая зона Excel, коммерческие коэффициенты и налоги вне текущего scope.

AI в расчёте не используется. Формулы, ручные количества, округления и ожидаемые значения зафиксированы явно в `input.json`, `expected.json` и коде калькулятора.

experiments/flat_roof_calculator/

## Что считает калькулятор

Калькулятор считает 31 строку серой внутренней сметы:

- подготовку основания как нулевую строку структуры;
- работу по пароизоляции;
- пароизоляционную плёнку;
- работу по утеплению ЭППС;
- ЭППС 100 мм;
- ЭППС 50 мм;
- уклонные плиты SLOPE A, B, J, K;
- геотекстиль 300 и 150;
- укладку ПВХ мембраны;
- примыкания ПВХ мембраны;
- примыкания к вентшахтам;
- прижимную и краевую алюминиевые рейки;
- ПВХ мембрану Logicroof;
- аэраторы;
- парапетные и внутренние воронки;
- пробивку отверстий в газоблоке;
- внутренний водосток ПВХ 110 мм;
- подъём материалов автокраном;
- расходные материалы и амортизацию инструмента;
- вывоз мусора;
- логистику и снабжение;
- технический надзор;
- заготовительно-складские расходы;
- нулевые строки структуры: накладные и общехозяйственные расходы, сметная прибыль.

## Что не входит

- временная дверь на проём ДН-1: это индивидуальная case-specific строка;
- клиентская/белая зона Excel;
- коммерческие коэффициенты;
- автоматический расчёт уклонных плит по геометрии кровли;
- автоматический расчёт базы логистики, расходников и заготовительно-складских расходов.

По сверке с Excel текущий итог калькулятора равен серой зоне Excel за минусом временной двери:

```text
Excel total:          2060872
Temporary door:        22000
Calculator total:    2038872
```

## Блоки расчёта

В `result.json` сохраняются структурированные блоки:

```text
calculation_blocks:
  geometry
  internal_drain
  pvc_membrane
```

Построчные формулы и raw/display значения сохраняются в `estimate_lines`.

## Ключевые формулы

### Геометрия

Legacy-режим `legacy_totals` использует готовые totals:

```text
roof_area_total_m2 = 248.92
parapet_and_abutment_total_length_m = 138.62
```

Production-режим `detailed_project_geometry` считает totals из проектных составляющих:

```text
roof_area_total_m2 = roof_area_level_1_m2 + roof_area_level_2_m2
248.92 = 177.52 + 71.40

parapet_and_abutment_total_length_m =
parapet_length_level_1_m
+ parapet_length_level_2_m
+ vent_wall_abutment_level_1_m
+ vent_wall_abutment_level_2_m

138.62 = 96 + 35.4 + 4.68 + 2.54
```

В production `roof_area_total_m2` и `parapet_and_abutment_total_length_m` не являются обязательными входными totals. Если они переданы, калькулятор использует их только как контроль и считает delta.

Площадь `294 м2` из спецификации хранится как контрольный показатель и не используется без ручной проверки.

### Пароизоляция

Работа:

```text
248.92 * 77 = 19166.84 -> 19167
```

Материал:

```text
required_area = 248.92 * 1.15 = 286.258
rolls = ceil(286.258 / 150) = 2
ordered_area = 300
material_total = 300 * 35 = 10500
```

### Утепление ЭППС

Работа:

```text
248.92 * 770 = 191668.4 -> 191668
```

Для текущего проекта ставка `770` вероятно соответствует `700 * roof_work_coeff 1.10`, но коэффициент оставлен входным параметром.

ЭППС 100 мм:

```text
required_volume = 248.92 * 0.2 * 1.03 = 51.27752
packs = ceil(51.27752 / 0.27376) = 188
ordered_volume = 188 * 0.27376 = 51.46688
display quantity = 51.47
material_total = 377080
```

По этой строке сумма зафиксирована для совпадения с текущей Excel-сметой из-за raw/display расхождения цены.

### Уклонные плиты

Объёмы SLOPE плит берутся от поставщика / Технониколь:

```text
A: 3.63 -> 13 packs -> 3.7908 м3 -> 41304
B: 5.61 -> 21 packs -> 5.7456 м3 -> 62604
J: 1.43 -> 5 packs -> 1.458 м3 -> 15886
K: 1.50 -> 6 packs -> 1.6416 м3 -> 17887
```

Калькулятор пока не строит раскладку уклонов сам.

### Геотекстиль

Геотекстиль 300:

```text
248.92 * 1.10 = 273.812
rolls = ceil(273.812 / 100) = 3
material_total = 300 * 111.76 = 33528
```

Геотекстиль 150:

```text
138.62 * 1.10 = 152.482
rolls = ceil(152.482 / 100) = 2
material_total = 200 * 64.34 = 12868
```

### ПВХ мембрана

Работа по плоскости:

```text
248.92 * 740 = 184200.8 -> 184201
```

Работа по примыканиям:

```text
138.62 * 700 = 97034
```

Материал Logicroof:

```text
flat_area = 248.92 * 1.15 = 286.258
abutment_area = 138.62 * 1.10 = 152.482
required_area = 438.74
roll_area = 2.10 * 20 = 42
rolls = ceil(438.74 / 42) = 11
material_total = 565738
```

По этой строке `11 * displayed price 51431 = 565741`, но в текущей Excel-смете стоит `565738`. Для совпадения с проверенной серой зоной сумма зафиксирована и вынесена в warning.

### Воронки, водосток и вывоз мусора

```text
Аэраторы: 3 * 587 + 3 * 2750 = 10011
Парапетные воронки: 2 * 5000 + 2 * 5500 = 21000
Пробивка отверстий: 2 * 3000 = 6000
Внутренние воронки: 3 * 5000 + 3 * 5500 = 31500
Внутренний водосток: 3 * 3.75 = 11.25 м
Водосток: 11.25 * 2500 + 11.25 * 3000 = 61875
Вывоз мусора: 3 * 10000 + 3 * 3500 = 40500
```

### Ручные строки текущего scope

```text
Подъём материалов автокраном = 30000
Расходные материалы = 75297.06 -> 75297
Логистика, и снабжение = 37648.53 -> 37649
Технический надзор = 10000
Заготовительно-складские расходы = 15000
```

Базы для логистики, расходников и заготовительно-складских расходов пока не автоматизированы.

## Raw vs Display

Калькулятор хранит:

- `quantity_raw`;
- `quantity_display`;
- `material_total_raw`;
- `material_total`;
- `work_total_raw`;
- `work_total`;
- `line_total_raw`;
- `line_total`.

Для итогов текущего раздела используются проверенные displayed/internal значения серой зоны. По строкам с raw/display расхождением предупреждения остаются в `result.md`.

## Важные ограничения

- AI не используется в расчёте.
- Не используются ссылки на Excel-ячейки как идентификаторы.
- Основные идентификаторы строк — смысловой `code` и название строки.
- Цены сейчас берутся из `input.json`.
- У материальных строк добавлен `price_code` для будущей связки с Google Sheets `price_registry`.
- Клиентская часть не считается.
- Временная дверь не включена в универсальный калькулятор.
